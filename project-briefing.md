# Project Brief - Advent Shop
Welcome to your first real project, working name "Advent Shop". This project's purpose is to teach you the best practices in software development. This isn't only for the technical skill, it also involves project management and agile methodology which is, I would argue, more integral than the technical side. 

## Goals & Learning Outcomes
1. Upskill in existing development frameworks and technologies(e.g. React, node).
2. Create good habits by instilling best practices.
3. Reinforce that AI-assisted development is not a bad thing and will help developers.
4. Introduce Agile project management practices.

## Tech Stack
### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js

### Database
- MySQL (Relational Database)

### Version Control
- Github

## AI-Assisted Development
As mentioned in the goals, AI will be used in this project. I will not prohibit the use of AI as the world is ever-evolving and we have to adapt to the times. However, prompting the AI is not easy and I will review the work that involves AI. Therefore, when using AI, you have to provide me with the following:
1. Your prompt
2. Skills you used
3. Type of model (e.g. Opus, Luna)
4. How and Why you implemented the AI's code

This ensures that you understand what AI outputs. You have the freedom to use any AI model you want, but make sure that it meets the standard of the work you are doing here.

## Project Management
There will be multiple people working on this project and there are areas that everyone should pay attention on. First, using Git you will collaborate with other developers on putting your work on Github so that you understand version control, and how you should append upon other's works.

Second, **DOCUMENT EVERYTHING**, and I mean everything. From the steps you took and to the rationale behind your work. You may use inline comments in the code. Always use self-describing variables. Ensure that you can backtrack each other's work and understand what it is for right away. To document I'll be creating a Notion Site that anyone should be able to access to understand what work is being done

Third, Agile methodology. We will be functioning as a working team with constant reviews and incremental work. When working make sure the changes you make are small and incremental so it is easy to review. We will be utilizing Github's issue tracking and Pull Requests to review and merge each other's work.

As we go on with this project, we will upgrade, evolve, and continuously develop more features. The tech stack is not static. Changes will be made to have an incremental impact on the developers as well. When developing, I am open to discussion on improvements and what we can add more to the project. What matters is you communicate well on what we should improve and you can justify why it works and why the project needs it. You should be able to justify well on what your idea is.
